# Accounting Learning Lab (core)
Semua file berada dalam SATU folder (tanpa subfolder): index.html, accounting.html, styles.css, i18n.js, engine.js, analyzer.js, app.js.
Run: buka folder di VS Code → Live Server → klik kanan `index.html` → Open with Live Server.
Deploy: upload semua file ke root repo GitHub → Settings → Pages → branch `main`, folder `/ (root)`. Semua path relatif.
Data tersimpan di localStorage browser (`alab.journal.v1`, `accountingLabLanguage`).
Urutan script: i18n → engine → analyzer → app.
